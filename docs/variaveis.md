# Variáveis em Go

Variáveis servem para armazenar valores.

## Exemplo

```go
package main

import "fmt"

func main() {
    nome := "Daiana"
    idade := 20

    fmt.Println(nome)
    fmt.Println(idade)
}
```

## Explicação

- `nome` guarda texto
- `idade` guarda número
- `fmt.Println()` mostra valores na tela
