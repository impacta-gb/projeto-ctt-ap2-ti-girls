# Variáveis em Go

Variáveis armazenam valores na memória.

## Exemplo

```go
package main

import "fmt"

func main() {

    nome := "Daiana"
    idade := 20

    fmt.Println(nome)
    fmt.Println(idade)
}
```

## Explicação

- `nome` armazena texto
- `idade` armazena números
- `:=` cria variáveis automaticamente
